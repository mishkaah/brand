## 1. فيزياء انبثاق النور والسكينة التراثية

تنفر الحركة في فلسفة مِشْكَاة من الحركات الرقمية المفاجئة أو الاستعراض البصري الصاخب؛ إذ تُحاكي الرسوم فيزياء انبثاق ضوء المصباح واستقراره في كُوّة المشكاة المحمية:

- **التباطؤ الوقور**: تبدأ الانتقالات بتمهل وتستقر برفق في سكينة وهيبة علمية تامة.
- **محاكاة مسار القلم**: تسير حركة رسم الحروف وفق المسار التلقائي لقلم الخطاط (القصبة)، محترمةً الاتجاه التاريخي للكتابة العربية من اليمين إلى اليسار.
- **التوازن التثاقلي لحركات التشكيل**: تهبط علامات التشكيل والنقاط بهدوء واستقرار عضوي على خط الكتابة.

## 2. منحنيات التباطؤ والمعادلات الرياضية

```
المنحنى الأول: sacredReveal [0.22, 1, 0.36, 1]
1.0 |                   .-------
    |                .-'
    |             .-'
    |          .-'
0.0 |________.'_________________
    0.0                        1.0

المنحنى الثاني: tashkeelFloat [0.34, 1.56, 0.64, 1] (استقرار مرن)
1.1 |              .---.
1.0 |             /     '-------
    |           .'
0.0 |_________.'________________
    0.0                        1.0
```

| معرف المنحنى | تعريف بيزييه التكعيبي | تمثيل CSS البرمجي | الدور الوظيفي |
| :--- | :--- | :--- | :--- |
| `sacredReveal` | `[0.22, 1, 0.36, 1]` | `cubic-bezier(0.22, 1, 0.36, 1)` | رسم مسار حلقة المدار الفلكي وانبساط حروف الكلمة الأساسية |
| `gentleEmerge` | `[0.16, 1, 0.3, 1]` | `cubic-bezier(0.16, 1, 0.3, 1)` | ظهور الشعار تدريجياً مع زيادة طفيفة في المقياس البصري |
| `tashkeelFloat` | `[0.34, 1.56, 0.64, 1]` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | استقرار حركات التشكيل ونقاط الإعجام بمرونة رأسية |
| `timelessSettle` | `[0.25, 0.1, 0.25, 1]` | `cubic-bezier(0.25, 0.1, 0.25, 1)` | مرور وميض البريق الهادئ والاستقرار التام للشعار |

## 3. مراحل مشهد الظهور المهيب الأربع

يمتد مشهد الظهور الرئيسي على مدى **`3.2 ثانية`** بمعدل 60 إطاراً في الثانية (192 إطاراً بالتمام):

```
الزمن (ثانية): 0.0       0.4           1.5         2.3         3.2
               |----------|-------------|-----------|-----------|
المرحلة 1:     [ الهالة والمدار الفلكي ]
المرحلة 2:                 [ رسم حروف الكلمة الأساسية ]
المرحلة 3:                               [ استقرار التشكيل ]
المرحلة 4:                                           [ البريق والاستقرار ]
```

### المرحلة الأولى: الهالة والمدار الفلكي (`0.0s – 0.9s`)
- **الهالة**: ينبثق تدرج ضوئي دائري في المركز `(512, 512)` متزايداً من شفافية `0.0` إلى `1.0` خلال `0.6s`.
- **حلقة المدار**: ترتسم حلقة المدار الفلكي الدقيقة (`r = 360`) باتجاه حركة عقارب الساعة بدءاً من موضع الساعة الثانية عشرة (`-π/2`) عبر خاصية `stroke-dashoffset` بالمنحنى `sacredReveal`.

### المرحلة الثانية: رسم حروف الكلمة الأساسية (`0.4s – 1.8s`)
- ينبسط جسم كلمة **مِشْكَاة** بسلاسة من اليمين إلى اليسار مقتفياً أثر ريشة الخطاط:
  1. عروة الميم الابتدائية وذيلها الهابط.
  2. أسنان الشين الثلاثة ووصلتها المتصلة.
  3. عصا الكاف المائلة الصاعدة.
  4. ألف المد الرأسية السامقة.
  5. دوران التاء المربوطة النهائي المقفل.

### المرحلة الثالثة: استقرار التشكيل والضبط (`1.5s – 2.5s`)
تهبط علامات الضبط تباعاً من إزاحة رأسية قدرها `+18px` وتستقر عبر المنحنى `tashkeelFloat`:
- `1.50s`: كسرة حرف الميم.
- `1.65s`: نقاط حرف الشين الثلاث.
- `1.80s`: سكون حرف الشين.
- `1.95s`: فتحة حرف الكاف.
- `2.10s`: نقطتا التاء المربوطة.

### المرحلة الرابعة: السكينة والوقار التام (`2.3s – 3.2s`)
يمر شريط انعكاس ضوئي مائل بزاوية `135deg` فوق الخطوط الذهبية خلال `0.9s`، ليستقر الشعار بعدها في سكون تام وثبات أبدي.

## 4. مشهد الانبثاق الهادئ السريع

للانتقالات السريعة وشاشات بدء التطبيقات والنوافذ المنبثقة، يوفر نمط **الانبثاق الهادئ** ظهوراً موجزاً في `1.6s`:
- **الشفافية**: تتدرج من `0.0` إلى `1.0` خلال `1.2s`.
- **المقياس**: ينمو بلطف من `0.96` إلى `1.00` انطلاقاً من المركز `(512, 512)`.
- **المنحنى**: `gentleEmerge` (`cubic-bezier(0.16, 1, 0.3, 1)`).

## 5. المواصفات الفنية لملفات الفيديو (60 FPS)

تلتزم مقاطع الفيديو الرسمية في المجلد `animations/video/` بالمعايير الهندسية التالية:

- **معدل الإطارات**: `60.00` إطاراً في الثانية ثابتاً (Constant Frame Rate).
- **المجال اللوني**: ITU-R BT.709 بالمجال الكامل `[0, 255]`.
- **مرمازات الفيديو**:
  - MP4: H.264 / AVC (High Profile Level 4.2), YUV 4:2:0.
  - WebM: VP9 مع دعم قناة الشفافية الكاملة (Alpha Channel).
- **نسب الأبعاد**:
  - `16:9` (`1920×1080`): الشاشات العريضة والعروض التقديمية.
  - `9:16` (`1080×1920`): منصات الفيديو الرأسية وشاشات الهواتف.
  - `1:1` (`1080×1080`): منشورات الشبكات الاجتماعية المربعة.

## 6. إمكانية الوصول وخيار تقليل الحركة

يجب على كافة التطبيقات ومواقع الويب احترام تفضيل المستخدم لتقليل الحركة:

```css
@media (prefers-reduced-motion: reduce) {
  .mishkaah-animated-mark {
    animation: none !important;
    stroke-dashoffset: 0 !important;
    opacity: 1 !important;
    transform: none !important;
  }
}
```
