## Overview

The **`docs/`** directory contains the official technical manuals, design specifications, and presentation collateral for the Mishkaah brand identity. These documents define the philosophical rationale, geometric formulas, and implementation rules required to maintain absolute visual and scholarly integrity across all platforms.
