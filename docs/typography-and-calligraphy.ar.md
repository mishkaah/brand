## 1. الخط العربي كعمارة مقدسة

يحظى القلم في الحضارة الإسلامية بمكانة سامقة نوه بها القرآن الكريم في مفتتح الوحي:

> ﴿اقْرَأْ وَرَبُّكَ الْأَكْرَمُ ۝ الَّذِي عَلَّمَ بِالْقَلَمِ ۝ عَلَّمَ الْإِنسَانَ مَا لَمْ يَعْلَمْ﴾ (سورة العلق: 3–5)

فالحروف العربية في تراثنا ليست مجرد ناقل بصري مجرد للألفاظ، بل هي ميزان هندسي رفيع يجمع بين التناسب الرياضي ووقار التدوين. وتنقسم منظومة الخطوط في مِشْكَاة إلى ست طبقات تخصصية، تضمن حصول النص القرآني ومتون التراث وعناصر الواجهات الحديثة على المعالجة الطباعية اللائقة بها شرعاً وهندسةً.

## 2. الطبقات الطباعية الست

```
+---------------------------------------------------------------------------------------+
| 1. طبقة الشعار والعلامات الخطية                                                       |
|    خط ديوان الثلث (مسارات بيزييه متجهة، استقلال تام عن تثبيت الخطوط)                  |
+---------------------------------------------------------------------------------------+
| 2. طبقة النص القرآني الشريف                                                          |
|    خط مصحف المدينة النبوية (مجمع الملك فهد) / الخط الأميري القرآني                     |
+---------------------------------------------------------------------------------------+
| 3. طبقة متون التراث والنصوص العلمية                                                   |
|    خط الأميري / الخط العربي التقليدي (متون الحديث، كتب التفسير، التراجم، الفقه)       |
+---------------------------------------------------------------------------------------+
| 4. طبقة واجهات المستخدم العربية الحديثة                                               |
|    خط SF Arabic (أنظمة آبل) / خط Noto Sans Arabic (أندرويد والويب)                     |
+---------------------------------------------------------------------------------------+
| 5. طبقة الأرقام والبيانات الوصفية اللاتينية                                          |
|    خط SF Pro Rounded / خط Inter (معرفات URN، أرقام الآيات، تواريخ التوثيق)            |
+---------------------------------------------------------------------------------------+
| 6. طبقة الشيفرات البرمجية ذات العرض الثابت                                            |
|    خط JetBrains Mono / خط SF Mono (سجلات المدقق، كائنات JSON، أدوات الطرفية)           |
+---------------------------------------------------------------------------------------+
```

## 3. مواصفات الطبقات بالتفصيل

### 3.1 الطبقة الأولى: الشعار الخطي الأصيل (*ديوان الثلث*)
- **الخط المعتمد**: *ديوان الثلث*. يُعد الثلث «سيد الخطوط العربية» لما يتمتع به من جلال ومهابة معمارية وتشابك تركيبي محكم.
- **آلية التوليد**: استُخرجت المسارات برمجياً عبر محرك CoreText في macOS إلى مسارات منحنيات بيزييه التكعيبية مباشرة.
- **الثوابت الأساسية**:
  - خلو ملفات SVG تماماً من أي وسوم نصية (`<text>`)، مما يضمن عرضها المتطابق على كافة الأجهزة دون تثبيت خطوط.
  - إدماج علامات التشكيل الكاملة هندسياً ضمن المسارات المتجهة.

### 3.2 الطبقة الثانية: النص القرآني الشريف (*خط مصحف المدينة النبوية*)
- **الخط الأساسي**: *خط مصحف المدينة النبوية برواية حفص* (الصادر عن مجمع الملك فهد لطباعة المصحف الشريف بالمدينة المنورة).
- **الخط البديل المساعد**: *الأميري القرآني*.
- **شرط قطعي**: يُحظر حظراً باتاً استخدام خطوط الواجهات الحديثة الخالية من التذييل (Sans-serif مثل Roboto أو Arial) لعرض الآيات القرآنية؛ لخلوها من علامات الضبط العثماني، وعلامات الوقف المعتمدة، وأشكال رؤوس الآيات.

### 3.3 الطبقة الثالثة: متون التراث والتحقيق العلمي (*الخط الأميري*)
- **الخط الأساسي**: خط *الأميري* للمصمم خالد حسني (إحياء رقمنة حروف مطبعة بولاق التاريخية بالقاهرة، 1924).
- **الخطوط البديلة**: *الأميري القرآني*، *Traditional Arabic*، *serif*.
- **الوظيفة**: عرض متون الأحاديث النبوية، وأسانيد الرواة، وشروح أئمة التفسير، والمسائل الفقهية.
- **المعالجة الطباعية**: ضبط تباعد الأسطر (Line-height) بين `1.8` و`2.0` لفسح المجال للحركات التشكيلية المتراكمة دون أي تداخل بصري.

### 3.4 الطبقة الرابعة: واجهات المستخدم العربية الحديثة (*SF Arabic* و *Noto Sans Arabic*)
- **بيئات آبل (iOS, macOS)**: خط *SF Arabic* مع نظام خطوط النظام المضمن.
- **بيئات أندرويد والويب**: خط *Noto Sans Arabic* من جوجل.
- **الوظيفة**: أشرطة التنقل، القوائم المنبثقة، الأزرار، وحقول البحث وإعدادات التطبيقات.
- **الأوزان الطباعية**: العادي (`400`) للعناوين الفرعية، المتوسط (`500`) للنصوص التفاعلية، شبه العريض (`600`) لعناوين الصفحات.

### 3.5 الطبقة الخامسة: البيانات الوصفية والأرقام (*Inter* و *SF Pro Rounded*)
- **الخطوط المعتمدة**: *SF Pro Rounded* (في آبل) / *Inter* (عبر المنصات).
- **الوظيفة**: أرقام الآيات (مثل `24:35`)، وعناوين المعرفات المسطحة (`mishkaah:entity:identity:...`)، والتواريخ الهجرية والميلادية.

### 3.6 الطبقة السادسة: الشيفرات البرمجية والسجلات (*JetBrains Mono*)
- **الخطوط المعتمدة**: *JetBrains Mono*, *SF Mono*, *Menlo*, *Consolas*.
- **الوظيفة**: عارض مستندات JSON-LD، ومخرجات أدوات التدقيق التلقائي، وسجلات الطرفية.

## 4. ميزات أوبن تايب (OpenType) والتشكيل التراكمي

لتفادي تداخل الحركات التشكيلية في النصوص المحققة، يجب تفعيل ميزات OpenType التالية برمجياً في المتصفحات والتطبيقات:

```css
.mishkaah-scripture-text {
  font-family: var(--mishkaah-font-quran);
  font-feature-settings:
    "liga" 1,   /* الحروف المركبة القياسية */
    "dlig" 1,   /* الحروف المركبة الاختيارية */
    "mark" 1,   /* مواضع الحركات */
    "mkmk" 1,   /* تراكم الحركات فوق بعضها */
    "calt" 1;   /* البدائل السياقية */
  text-rendering: optimizeLegibility;
  line-height: 2.2;
}
```

```css
  --mishkaah-font-classical: "Amiri", "Amiri Quran", "Traditional Arabic", serif;
  --mishkaah-font-arabic-ui: "SF Arabic", "Noto Sans Arabic", -apple-system, system-ui, sans-serif;
  --mishkaah-font-latin-ui: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
  --mishkaah-font-mono: "JetBrains Mono", "SF Mono", Menlo, Consolas, monospace;
}
```
