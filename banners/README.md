## Overview

The **`banners/`** directory contains visual banners, OpenGraph social preview cards, and repository pillar headers for the entire Mishkaah ecosystem. Each banner is designed with mathematical restraint, scholarly calm, and consistent typographic hierarchy reflecting the verse from Surah Al-Nur.

## Layout Specifications

1. **Aspect Ratios**:
   - Organization Profile Header: `16:5` (`1600×500`)
   - Social OpenGraph Cards: `2:1` (`1280×640`)
   - Repository Readme Headers: `32:10.5` (`1280×420`)
2. **Typography Hierarchy**:
   - Brandmark: Classical *Diwan Thuluth* calligraphy.
   - Arabic Pillar Slogan: *Amiri* / *SF Arabic* at optical weight `500`.
   - English Pillar Slogan: *SF Pro Rounded* / *Inter* with `0.08em` tracking.
3. **Contrast Compliance**: Every banner maintains a minimum contrast ratio of `11.4:1` (WCAG AAA) between the obsidian canvas (`#09090B`) and golden foreground typography (`#E5CFA0` → `#B89655`).
