## نظرة عامة

يضم مجلد **`scripts/`** حزم البناء البرمجية وأدوات استخراج المسارات المتجهة وفحوصات التكامل المستمر (CI) الخاصة بمستودع هوية مِشْكَاة. كُتبت كافة الأدوات بلغة TypeScript وتعمل بصورة حتمية فائقة السرعة عبر بيئة [Bun](https://bun.sh) دون الحاجة إلى لغة Python أو أي مكتبات خارجية معقدة.

---

## فهرس الأدوات البرمجية

| مسار الأداة | المهمة والمسؤولية الأساسية | أمر التشغيل |
| :--- | :--- | :--- |
| [`build-tokens.ts`](./build-tokens.ts) | تجميع ملفات JSON المحايدة للمتغيرات التصميمية في حزم برمجية جاهزة للإنتاج (`tokens.css`, `tokens.ts`, `mishkaah_tokens.dart`). | `bun run scripts/build-tokens.ts` |
| [`verify-brand-integrity.ts`](./verify-brand-integrity.ts) | أداة التدقيق الصارم لسلامة ملفات JSON، والتحقق من نقاء مسارات الرسوم المتجهة، ومطابقة التوثيق المزدوج، وخلو النصوص من وسوم الرياضيات الممنوعة. | `bun run scripts/verify-brand-integrity.ts` |

## بوابات التدقيق التلقائي (CI Gates)

عند تشغيل أداة [`verify-brand-integrity.ts`](./verify-brand-integrity.ts) ضمن سير عمل GitHub Actions، تُطبق أربع بوابات تدقيق صارمة:

1. **صحة ملفات الرموز والمتغيرات**: التأكد من سلامة صياغة ملفات JSON في مجلد `tokens/` وخلوها من الأخطاء النحوية أو الحقول الناقصة.
2. **نقاء الرسوم المتجهة واستقلال الخطوط**: التحقق من خلو ملفات SVG في `logos/` و`app-icons/` و`banners/` من أي وسوم نصية حية (`<text>`)، وضمان اعتمادها بالكامل على مسارات بيزييه التكعيبية المغلقة (`<path>`).
3. **تطابق التوثيق الثنائي المتزامن**: التحقق من احتواء كل مجلد فرعي في المستودع على دليل باللغة الإنجليزية `README.md` وقرين متطابق باللغة العربية الفصحى `README.ar.md`.
4. **حظر صيغ الرياضيات المعقدة في التوثيق**: فحص كافة ملفات `.md` للتأكد من عدم استخدام علامة الدولار (`$` أو `$$`) الخاصة بـ LaTeX خارج الكتل البرمجية.

## الاستخدام والتشغيل المحلي

### المتطلبات الأساسية
- تثبيت بيئة [Bun](https://bun.sh) (الإصدار `1.0.0` أو أحدث).

### تجميع حزم المتغيرات
لإعادة بناء حزم CSS وTypeScript وDart بعد تعديل أي ملف في `tokens/`:
```bash
bun run scripts/build-tokens.ts
```

### تشغيل حزمة التدقيق والتحقق
للتحقق من سلامة كافة أصول الهوية ومستنداتها محلياً:
```bash
bun run scripts/verify-brand-integrity.ts
```
