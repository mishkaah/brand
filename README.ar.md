### الألوان الأساسية

- **الداكن المطفي** (`#09090B`): خلفية هادئة للقراءة الليلية.
- **الذهب التراثي** (`#E5CFA0` ← `#B89655`): لون الخط واللمسات الجمالية.
- **بياض الورق** (`#F6F3EC`): محاكاة لورق المخطوطات في القراءة النهارية.
